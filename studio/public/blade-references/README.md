# Exact-blade photographic references

These are photographs of the ten named historical presets, not the separate Met
Museum reference collection. Original source images are stored in a directory
named for each blade. Additional close-ups are explicitly unregistered and are
not registered to the camera view. The app links to the original photograph
through More; the automatic enlarged comparison panel has been removed.

The user confirmed permission to include the dealer photographs in this repository
on November 4, 2026. Copyright remains with the source photographers/dealers.
These files are **not public domain or CC0**, and this repository does not grant
independent redistribution rights. Source pages, image URLs, checksums and the
permission basis are recorded in `manifest.json`.

The manifest records approximate blade-base/tip pixel coordinates and a crop
isolating one photographed face from composite source images. Published nagasa
provided the former approximate pixel-to-millimeter scale. This metadata is
retained for provenance, but is no longer used for automatic image transforms.
Source perspective and endpoint uncertainty remain uncalibrated.

The Ayanokoji and Tametsugu full-blade photographs have substantially less spatial
resolution than the other references. Enlarging those crops does not provide
useful material detail, so the comparison feature was withdrawn. Higher-detail
close-ups remain in the archive; their exact positions and coverage are not
established.
